# 十五境总表与档位映射

> 骨架：《剑来》练气士十五境。本质：MetaThink 深度思考与 AI 协同能力。
> 三维模型：认知进阶（内功）× 驭智段位（技法）× 人机协同境界（形态）。

## 核心规则（评定时的世界观）

1. **认知决定驭智上限，驭智决定协同空间。** 认知不到位，prompt 再花哨也到不了 S3——不知道该给 AI 定什么框架。
2. **能力抽象定境段上限，行为贡献定段内进度。** 本 skill 评的是前者（五档）；段内哪一境由平台侧的输出/互动数据决定，不归本 skill 管。
3. **模式无高低。** 请教/指挥/指导/研究四模式只有适配问题。认知不够时强用研究模式只会产出伪创新。
4. **11 境以上是治理与声望，不是能力。** 对话证据只能认证档 5 门槛，晋升由提名、选举、时间检验决定。

## 境段速览（评定报告中引用叙事时用）

**下五境 · 炼体筑基（1–5）**：从门外到门内。全数据驱动升级，本 skill 在此段的作用是自评定位与修行任务，不是升级审批。
- 铜皮："淬炼皮肉，方知世间有修行一道。"
- 草根："草根萌发，灵气初生。你的思考开始扎根。"
- 柳筋："柳筋舒展，柔韧自如。你已不再是生硬的工具使用者。"
- 骨气："骨骼如铁，自有风骨。你对 AI 的输出开始有自己的判断。"
- 筑庐："筑庐于内，灵气归藏。你已踏入真正的修行之门。"

**中五境 · 灵气贯通（6–10）**：从消费者到贡献者。
- 洞府："开辟洞府，自成天地。你开始有自己的声音。"
- 观海："观海听涛，灵气反哺。你已是这片天地中重要的存在。"
- **龙门（渡劫节点）**："鱼跃龙门，逆流而上。内功、技法、形态，三维并进，方算化龙。" 唯一有跌境风险的节点，三维同步跃迁：认知 精→绝、驭智 S3→S4、协同 L3→L4。本 skill 的龙门初审对应场景 B。
- 金丹："金丹凝结，万法归一。你的思考已自成体系。"
- 元婴："元婴初成，生生不息。你的思想开始有了自己的后代。"

**上五境 · 超凡入圣（11–15）**：从贡献者到治理者。晋升靠提名/选举/时间检验，本 skill 只认证档 5 能力门槛。
- 玉璞："大巧若拙，返璞归真。" 仙人："仙人抚顶，天地共鸣。" 飞升："天地不容，唯我独行。"
- 失传一/二：传说与永恒，预期社群前 5 年可能无人到达。

## 龙门境「公开论道」考核结构（场景 B 的依据）

| 步骤 | 展示内容 | 考核维度 |
|------|------|:--:|
| 1 选题 | 真实问题（商业分析/个人成长/学习困惑） | — |
| 2 展示过程 | 完整思考过程：怎么拆解、选了哪个 skill、为什么、纠偏在哪、洞察如何浮现 | 认知 |
| 3 展示技法 | prompt 迭代全程：初版→发现问题→调整→终版，每次调整的依据 | 驭智 |
| 4 展示协作 | 选了什么协作模式、为什么、人与 AI 判断之间的博弈 | 协同 |
| 5 白纸重建 | 脱离 AI 现场重推核心逻辑（本 skill 强制要求） | 认知（防伪） |

社群评审从三维分别打分（各 1–5），本 skill 出具初审报告供其参考。
通过 = 化龙晋金丹；不通过 = 跌回观海，冷却 30 天，出具跌境诊断报告（场景 C）。
