# 报告模板

> 三种报告都遵循同一条铁律：每个判定必须附证据原文引用。写不出引用的判定删掉。

## 模板 A：自评定位报告

```markdown
# 境界评定 · 自评定位报告

**修士**：（称呼）  **评定日期**：  **证据包**：（N 段对话，类型覆盖情况）

## 一、评定结论

- **能力档位**：档 X · XX段（如：档 3 · 框架驱动）
- **对应境段**：X–X 境（段内具体境界由社群行为数据决定）
- **三维定位**：认知进阶 XX ｜ 驭智段位 SX ｜ 协同 XX模式 / LX
- **置信度**：高 / 中 / 低（理由一句话）

## 二、证据表（判定依据）

| 信号/排除项 | 判定 | 证据原文 | 出处 |
|------|:--:|------|------|
| P1 约束设定 | ✓ | "（用户原话）" | 样本② |
| P3 先答后问 | ✗ 未发现 | — | 全部样本 |
| G3 框架型假懂 | 触发 | "（用户原话）" | 样本② |
（只列与本次档位判定相关的行）

## 三、卡在哪里（升档的具体瓶颈）

（指出封顶的那条负向门或缺失的那个正向信号，引用样例对说明差距长什么样）

## 四、修行任务（下一档 3 项，具体到动作）

1. （针对瓶颈的可执行任务，如："下一个熟悉领域的任务，在让 AI 分析之前，先写下你自己的初判并要求 AI 攻击它——把这段对话留作下次评定的证据"）
2. …
3. …

## 五、红旗与备注

（防伪红旗记录；若无：无。补充证据可复核升档的说明。）

> 叙事收尾：引用当前境界的一句话叙事文案。
```

## 模板 B：龙门初审报告

```markdown
# 龙门境论道 · 初审报告（供人类评审终审用）

**冲关修士**：  **护道人**：  **论道选题**：  **初审日期**：

## 一、初审结论

**建议通过 / 建议不通过 / 证据不足**（本报告为初审，终审权在金丹境以上评审团）

## 二、三维分项初评（各 1–5 分）

### 认知（思考过程）：X/5
- 问题拆解质量：（判定+引用）
- 纠偏与洞察浮现：（判定+引用）
- 方法论元素检测：多层追问 ✓/✗ ｜ 框架切换 ✓/✗ ｜ 假设验证 ✓/✗（各附引用）

### 驭智（prompt 迭代）：X/5
- 迭代逻辑成立性：每次调整是否有依据（判定+引用）
- 划界动作（P5）：（判定+引用）

### 协同（模式博弈）：X/5
- 模式选择与认知的匹配度：（判定+引用）
- 人的增量贡献（P9）：最终洞察中哪些是 AI 未曾提出的（判定+引用）

## 三、白纸重建结果

- 核心逻辑重推：通过 / 未通过（记录现场变形追问及回答要点）
- 未安排白纸重建 → 本报告结论自动改为「证据不足」

## 四、请人类评审重点核查的点

（红旗、摇摆判定、需要现场追问确认的地方——把机器不确定的地方明确交给人）
```

## 模板 C：跌境诊断报告

```markdown
# 跌境诊断报告

**修士**：  **诊断日期**：  **冷却期至**：（30 天后日期）

## 一、短板定位

**三维中的短板维度**：认知 / 驭智 / 协同（可多选，按严重度排序）

| 维度 | 初审得分 | 短板具体表现 | 证据原文 |
|------|:--:|------|------|

## 二、短板的病理（对应哪种假懂/割裂）

（用四种假懂/伪学习伪行动的语言点名病症，并解释为什么这次论道暴露了它）

## 三、30 天补强路径（按周）

- **第 1 周**：（针对病症的具体练习，必须是"做"不是"学"——学行一体）
- **第 2 周**：
- **第 3 周**：
- **第 4 周**：（模拟论道自测：对照 rubric 样例对 C 自查三处——沉淀是否被检验、方法带不带边界、痕迹是否具体）

## 四、再冲关检查清单

- [ ]（本次失败的每一处短板对应一个检查项）
- [ ] 新论道材料中包含至少一次前轮沉淀被检验的记录（P6）
- [ ] 能陈述自己方法的失效边界（P7）

> 收尾：跌境不毁道基。二次化龙者，社群会记得更久。
```
