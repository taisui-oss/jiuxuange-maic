# 九轩阁 MAIC 双入口 V1 实现与验证

日期：2026-07-26

## 1. 本轮目标

[KNOWN, HIGH] 首页不再让“通用 MAIC 对话”和“商业模式大课”看起来像两套互相竞争的学习产品。新结构为：

```text
九轩阁 MAIC 学习门户
├── 我的课程
│   └── 商业模式大课：复用现有 V5 持续课堂与 projectV2 进度
├── 个人项目测评
│   └── 小组共享冻结项目卡 + 个人独立两次提交
└── 自由学习
    └── 个人上传与自由对话，不改变课程进度或测评证据
```

## 2. 已实现

### 2.1 服务端领域合同

- `CourseVersion`
- `CourseEnrollment`
- `LearningSession`
- `GroupMembership`
- `ProjectCardVersion`
- `AssessmentAssignment`
- `AssessmentSession`
- `AssessmentAttempt`
- `ActivityEvent`

[KNOWN, HIGH] 正式课程进度没有复制到新门户状态；门户中的课程会话只允许指向现有 `stageId`，课堂运行时真相仍为 `scene.content.projectV2`。

### 2.2 本机持久化与身份边界

- 新增 `data/jiuxuange-portal/portal-state.v1.json` 原子 JSON 持久化。
- localhost/127.0.0.1 可使用固定演示学员。
- 非回环地址默认拒绝无身份访问。
- 正式部署只有在私有网关显式开启可信身份头后，才读取 `x-jiuxuange-learner-id`。

[KNOWN, HIGH] 这是 L0 本机仓库，不是生产数据库或现有花名系统接入。

### 2.3 个人项目测评

- 发布任务冻结项目卡版本、题目版本、Prompt 版本和 rubric 版本。
- 同组成员获得相同项目卡和六道题，但测评会话、草稿、提交和反馈隔离。
- 草稿不消耗机会。
- 第一次正式提交只返回方向性反馈，不提供参考结论。
- 第二次提交比较两次原文，生成非分数最终反馈并锁定。
- 课程完成状态不阻塞管理员已发布的测评。

### 2.4 活跃时长

- 只记录 `course`、`free_learning`、`assessment` 三类活跃时间。
- 心跳间隔最多记 60 秒。
- 页面不可见或最近 120 秒无交互时记 0 秒。

[KNOWN, HIGH] 当前只在新测评页发送心跳；正式课程和自由学习页面的服务端心跳尚未接线，因此三类报表还未完整。

## 3. 已验证

- 领域与 API 合同：同组同题、个人隔离、未发布拒绝、草稿不耗机会、两次锁定、课程弱关联、挂机不计时。
- 原有 V5 会话恢复、状态、视图与非分数反馈回归没有行为退化。
- TypeScript 通过。
- ESLint 0 error；首页保留 1 个既有 Hook dependency warning。
- Next.js 生产构建通过，并包含 `/assessment/[assignmentId]` 与四个 `/api/jiuxuange/*` 路由。
- `http://127.0.0.1:8794/` 桌面与 390px 移动端浏览器验收通过。
- 测评草稿保存后刷新可恢复，正式提交次数仍为 `0/2`。
