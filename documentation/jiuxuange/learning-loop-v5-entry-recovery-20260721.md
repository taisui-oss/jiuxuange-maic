# 学习闭环 V5.1 首页入口与新一轮恢复合同

## 1. 触发问题

[KNOWN, HIGH] 2026-07-21 的本机页面把通用对话框放在商业模式大课入口之前；完成态课程按钮显示“回看学习”，点击后按原稳定会话键返回已完成的旧聊天。

[KNOWN, HIGH] 这会同时造成两个错误认知：学员看不出正式课程入口在哪里，也无法区分“重新学习”和“回看历史”。

## 2. V5.1 固定行为

| 学习状态 | 主操作 | 次操作 | 会话行为 |
|---|---|---|---|
| 未开始 | 开始学习 | 无 | 创建基础 V5 会话 |
| 进行中 | 继续学习 | 无 | 恢复最新一轮的当前节点 |
| 已完成 | 开始新一轮 | 回看上次 | 新一轮创建独立课堂；旧记录保持不变 |
| 不可用 | 开始学习 | 无 | 重新建立基础 V5 会话 |

[KNOWN, HIGH] 商业模式大课入口在首页视觉顺序中位于通用对话框之前。两者继续共存时，正式课程入口拥有第一操作层级。

[KNOWN, HIGH] 新一轮使用项目标识 `business-model-learning-loop:attempt:<attemptId>`，仍由 `learnerId + courseId + projectId + packageVersion` 唯一定位。没有新增数据库表，也没有覆盖旧 `scene.content.projectV2`。

[KNOWN, HIGH] 首页恢复会在同一学员、课程和课程包版本下选择最近创建或更新的 V5 轮次；“回看上次”直接进入完成态记录的原课堂。

## 3. 版本边界

[KNOWN, HIGH] 本次产品行为版本记为 `V5.1`，课程包仍为 `5.0.0-learning-loop-pilot`。原因是课程节点、教材、案例事实、披露边界和证据合同均未变化。

[KNOWN, HIGH] 旧 V3、V4、V5 会话不迁移、不删除。关闭 `NEXT_PUBLIC_C_CUBIC_LEARNING_LOOP_V5` 仍恢复 V4。
