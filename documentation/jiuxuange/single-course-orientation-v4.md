## 已确认边界

1. 单课导学属于商业模式大课本身，不是进入课程前的资格审查。
2. 新学员点击课程后直接进入统一对话工作台，并立即获得必要知识片段。
3. 导学只包含“课程必知必会、固定案例观察、六要素最小地图”。
4. 个人学习成果测评不属于导学，不得出现在导学开场、导学问题或导学推进条件中。
5. 学员回答“不知道”、短回答或非标准表达时，系统提供解释并允许继续；不得重复原问题形成死循环。
6. V3 及更早会话按原课程包恢复，不迁移、不覆盖。

## V4 导学链

```text
必知必会：商业模式不等于产品或收入
→ 固定案例：便利蜂如何改变门店决策与协作关系
→ 六要素最小地图：识别要素之间的连接
→ 第 1 关：定位
```

每个导学任务采用“短讲授 → 一个观察问题 → 记录回答 → 继续”的节奏。回答质量用于区分自主证据与辅助推进，不再决定学员是否有资格进入课程。

## 状态与故障原则

- V4 不创建旧版 `problem → baseline → goal → assessment_contract` 导学状态。
- 导学回答不满足证据规则时，记录 `assisted` 推进事件并开放“完成/继续”。
- LLM 超时、空输出或格式错误时，使用课程包中的确定性讲授文本；不重复问题、不自动生成成绩。
- 课程进度仍由 PBL milestone/microtask 推导，不建立第二份进度表。
