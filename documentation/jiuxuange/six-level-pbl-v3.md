# 六关 PBL 学习链 V3 实施记录

## 版本边界

- 课程包版本：`3.0.0-six-level-pbl`
- 稳定项目 ID：`six-level-pbl`
- 功能开关：`NEXT_PUBLIC_C_CUBIC_SIX_LEVEL_JOURNEY=true`
- 回退方式：关闭该开关，首页恢复选择 `2.0.0-guided-course`；V3 会话数据不迁移、不删除。

## 已实现

- 六关课程地图：定位、业务系统、关键资源能力、盈利模式、现金流结构、企业价值。
- 六关进度完全由既有 PBL milestone/microtask 状态派生，不保存第二份进度。
- 每关固定四类任务：概念表达、真实项目应用、边界挑战、判断修正。
- 便利蜂与生鲜零售案例保留盲解、提交、解锁、比较结构。
- 项目应用任务只接受已核验的 `primary_project` 事实；首页陈述仅保存为待核验草稿。
- 证据门区分自主、提示后、答案泄露与无依据表达；模型文本不能直接迁移状态。
- “换个角度再想一次”只提升当前任务支架等级，保留历史、证据和进度。
- 超时或空输出继续使用确定性下一问，不自动产生证据或完成任务。
- 最终学习回顾显示六关完成情况、判断修正、自主/提示后证据和未解决问题，不显示数字总分。
