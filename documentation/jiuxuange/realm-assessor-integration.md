# MetaThink 十五境评定接入

## 定位

MetaThink `metathink-realm-assessor` 作为九轩阁「成长反馈官」的平台级专项能力接入，不作为商业模式课程的教学 Agent，也不参与 PBL 节点推进。

原因是两类评价的对象不同：

- 课程评价看学员是否学会商业模式概念、案例分析和迁移判断。
- 十五境评定看学员在多任务、多时段中是如何驾驭 AI 进行认知建构的。

## 已实现

1. 原 Skill `v1.0` 及 `rubric / realms / evidence / templates` 作为版本化服务端资产归档。
2. 建立三种场景的确定性证据门：自评定位、龙门初审、跌境诊断。
3. 自评定位强制要求 3–5 份近三个月原始对话，覆盖陌生领域、熟悉领域和多轮迭代。
4. 龙门初审缺少白纸重建时不运行评定。
5. 模型评定使用结构化 JSON；`confirmed / triggered` 判定必须引用某份样本中逐字存在的原文。
6. 原文无法回溯、低置信度却给出等级、模型不可用时，系统不生成替代结论，转为人工复核。
7. 服务端接口为 `POST /api/c-cubic/realm-assessor`。

## 尚未实现

- 没有学员端证据提交界面。
- 没有跨课程、跨会话的服务端证据索引。
- 没有学员对历史对话进入评定的单独授权和脱敏确认。
- 没有人类评审工作台、终审和社群投票链路。
- 没有用人工金标准验证模型档位判定的偏差。

因此，当前状态是「可调用的服务端初审内核」，不是「学员已可在前台完成境界评定」。

## 下一个真实闭环

1. 学员在学习与日常 AI 协作中主动标记候选证据，系统不自动把所有对话送审。
2. 成长反馈官检查类型覆盖、时间和原始性，只在证据门通过后开启评定。
3. AI 生成可回溯的初审结果，人类评审看原文、红旗和模型不确定项。
4. 用人工结论与 AI 初审的偏差继续校准 rubric；未达到偏差门槛前，不对学员宣告正式境界。
