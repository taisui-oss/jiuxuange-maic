# 商业模式大课交互体验与学习深度缺口（2026-07-22）

## 1. 第一性原理判断

[INFERRED, HIGH] 学习伙伴的最小有效闭环不是“学员回答后系统进入下一页”，而是：学员先暴露原判断，系统提供恰当教学动作，学员在新材料上产生可观察变化，系统如实反馈变化与未形成部分。

[KNOWN, HIGH] 当前回放完成了对话推进、案例顺序、状态保存和最终反馈生成。

[KNOWN, HIGH] 当前回放没有形成足以证明独立判断、迁移或修正的学员输出。

[INFERRED, HIGH] 根本矛盾是：系统把“流程不能卡住”实现成“任意非空回应都可结束节点”，却没有把“节点结束前必须发生最小教学补偿”实现成同等强度的合同。

## 2. 三类状态必须分开

| 状态 | 定义 | 是否允许推进 | 最终反馈允许用词 |
|---|---|---|---|
| `attempted` 尝试过 | 学员留下非空回应，但未完成当前学习动作 | 是 | 尝试、尚未形成、尚未完成 |
| `taught` 已讲授 | Agent 已给节点专属解释或支架，学员可能仍未证明会用 | 是 | 已获得解释、在支架下尝试 |
| `demonstrated` 已表现 | 学员用事实完成当前要求的判断或迁移 | 是 | 独立形成、在提示后形成、完成迁移 |

[KNOWN, HIGH] 当前数据模型主要记录 `autonomous / hinted / assisted / unsupported`，但可见文案把 `assisted` 经常写成“形成了”“完成了”。

[INFERRED, HIGH] `assisted` 既可能表示“获得了教学但未表现”，也可能表示“在支架下表现出来”；这两个含义必须拆开，否则学习反馈不可解释。

## 3. 本次回放的逻辑断层

### 断层 A：支架重复，教学没有增量

[KNOWN, HIGH] 必知必会短讲重复三次；问题变化了，但讲授内容没有根据学员回答变化。

[INFERRED, HIGH] 学员感受到的是重复追问，而不是“系统读懂了我缺哪一步”。

### 断层 B：事实观察没有被确认或纠偏

[KNOWN, HIGH] 学员回答“中央大脑”后，系统只说“没关系，我们先把这一点讲清楚”，没有说明这个回答与哪条事实、哪项决策动作相关。

[INFERRED, HIGH] 系统失去了把口语对象转换为可引用项目事实的机会。

### 断层 C：不知道之后没有真正教学

[KNOWN, HIGH] 学员在便利蜂判断和最终修正阶段回答“不知道”，系统没有提供节点专属解释，只记录“辅助理解”并继续。

[INFERRED, HIGH] 非阻塞规则成立了，学习补偿没有成立。

### 断层 D：迁移任务难度与支架不匹配

[KNOWN, HIGH] 迁移题要求“关系差异 + 履约成本 + 两条事实”，学员只答“物流”。系统没有拆解为可完成的下一步，也没有要求选择具体模式或事实。

[INFERRED, HIGH] 单问原则不等于一次只能给一个大问题；深度学习需要把复合任务拆成可观察的单步动作。

### 断层 E：最终反馈不忠于证据

[KNOWN, HIGH] “不知道”被表述为形成判断和作出修正，“物流”被表述为完成迁移。

[INFERRED, HIGH] 这会同时伤害学员信任和后台评估有效性。它不是措辞瑕疵，而是结果语义错误。

## 4. 下一条可验证的学习闭环

```text
初始判断
→ 80-140 字必知必会讲授
→ 一个概念区分
→ 便利蜂 3 条编号事实
→ 选择“谁的什么动作改变”
→ 形成一条“事实—关系—结果”判断
→ 解锁课程解释并比较遗漏
→ 生鲜新情境只换案例、不换判断结构
→ 明确写出修正或明确记录未形成修正
→ 证据忠实的非分数反馈
```

[INFERRED, HIGH] 这条闭环的首要验证对象不是完成率，而是三件事：学员能否指出事实、能否说出关系变化、能否在新案例中复用同一判断结构。

## 5. 节点级修复顺序

1. [INFERRED, HIGH] 先修反馈真实性：任何 `unknown`、无事实短词和 unsupported 回应不得写成形成判断、完成迁移或作出修正。
2. [INFERRED, HIGH] 再修弱回答教学补偿：每个节点配置专属微讲授和低摩擦补全问题，禁止统一使用“没关系，我们先讲清楚”。
3. [INFERRED, HIGH] 再修角色所有权：角色由节点显式声明，冻结合同与运行时保持一致。
4. [INFERRED, HIGH] 再修问题拆解：复合题拆成“选事实 → 说关系 → 说结果”，一次长回答不能越过多个证据门。
5. [INFERRED, HIGH] 最后做真实学员回放：至少覆盖高表达、低表达和连续不知道三类，不用模拟通过代替真人学习效果。

## 6. 发布判断

[KNOWN, HIGH] 当前版本可以作为流程原型和状态机演示。

[INFERRED, HIGH] 当前版本不应作为“已能深度辅助学习”的版本开放，因为回放显示系统能在关键学习动作未发生时完成全流程，并生成过度肯定的反馈。

[INFERRED, HIGH] 下一版放行门槛应增加：固定回放中，弱回答必须触发节点专属教学补偿；最终反馈必须逐条忠于原始消息和事实引用；节点角色必须与设计合同一致。
