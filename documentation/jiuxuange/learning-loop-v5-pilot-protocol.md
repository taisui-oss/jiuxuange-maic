# 学习闭环 V5 单人试学协议

适用版本：`5.0.0-learning-loop-pilot`  
目的：验证一名真实学员是否能在无旁人代答的情况下完成便利蜂学习与生鲜迁移。

## 1. 试学前提

- 使用一个没有 V5 历史记录的浏览器环境进入 `http://127.0.0.1:8792/`。
- 学员只知道自己正在学习商业模式，不提前阅读便利蜂或生鲜案例结论。
- 观察者可以记录卡点，但不得解释题目、提示事实编号或修改学员回答。
- 保留课程包版本、开始时间、结束时间和最终课堂 URL。

## 2. 必跑路径

```text
教学前判断
→ 必知必会短讲授
→ 便利蜂事实观察
→ 便利蜂独立判断
→ 解锁课程解释并比较
→ 生鲜零售新情境迁移
→ 修正判断
→ 阅读非分数反馈
→ 关闭并重新打开同一课堂
```

## 4. 教练复核

试学结束后，从课堂顶部下载菜单选择“导出课堂 ZIP”。教练在 `manifest.json` 中读取：

```text
scenes[].content.projectV2.threads[].messages
scenes[].content.projectV2.jiuxuange.learningLoop.claims
scenes[].content.projectV2.jiuxuange.learningLoop.disclosures
scenes[].content.projectV2.jiuxuange.learningLoop.revisions
scenes[].content.projectV2.jiuxuange.learningLoop.feedback
```

[KNOWN, HIGH] 导出往返测试已锁定上述 V5 证据字段。课堂 ZIP 包含学员原始对话，只能在本轮授权的本机教练复核中使用，不得作为公开样本传播。

教练只依据原始消息和案例事实回答：

1. 教学前判断是否在讲授前保存。
2. 便利蜂判断是否在课程解释解锁前独立形成。
3. 生鲜回答是否同时包含事实、关系变化和可能结果。
4. 系统是否把“不知道”或纯复述误记为自主掌握。
5. 修正判断是否相对最初判断发生可说明的变化。
6. 最终反馈中的每条事实与主张是否能回到原始记录。
7. 重新进入后是否恢复到退出时的节点和内容。

## 5. 结果定义

- **A：独立迁移成立**：生鲜回答存在有效自主证据，且反馈引用全部可核验。
- **B：支架后完成**：流程完成，但生鲜迁移需要提示；反馈必须明确区分辅助与自主。
- **C：迁移未成立**：流程可以完成，但生鲜回答没有形成事实到关系结果的有效连接。

[KNOWN, HIGH] A、B、C 只描述本轮学习表现，不是正式分数或稳定能力等级。

## 6. 通过门槛

- 学员完成整条路径，没有因“不知道”或非标准回答永久卡住。
- 提交便利蜂判断前没有看到课程分析。
- 系统没有虚构案例事实，也没有把辅助理解写成自主掌握。
- 关闭再进入后恢复同一会话。
- 教练能核验反馈中的全部证据引用。

任一高危问题出现，本轮判定失败并新增固定回归样本：答案提前泄露、事实虚构、辅助冒充掌握、会话丢失、反馈引用无法解析。
