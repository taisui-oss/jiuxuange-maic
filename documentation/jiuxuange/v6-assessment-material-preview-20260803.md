## 本次实现

1. 个人测评改为六题单题作答工作台，支持题目导航、前后切换、草稿保存和两次正式提交。
2. 每题展示可引用的冻结项目事实，不读取个人研习或小组讨论记录，不提供 Agent 实时帮答。
3. 项目资料区增加“上传材料 / 项目卡 / 全部事实”三个视图。
4. “上传材料”显示材料名称、页数、解析状态、脱敏状态、安全摘要和从材料中提取的可见项目卡字段。
5. 项目卡冻结快照新增材料元数据和上下文分区；`block` 字段不进入测评数据契约。
6. 空白草稿不保存、不计入“已回答”，学员清空后可回到 `0/6` 状态。
7. 桌面使用右侧固定资料区；手机使用资料抽屉，长项目名不再挤压版本和关闭控件。
