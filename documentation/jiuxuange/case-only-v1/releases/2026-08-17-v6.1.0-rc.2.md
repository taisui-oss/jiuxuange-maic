# 九轩阁 MAIC 6.1.0-rc.2 五案例完整课堂发布记录

## 发布决策

- 产品版本：`6.1.0-rc.2`
- 名称：九轩阁 MAIC 五案例完整课堂候选版
- 发布通道：`preview-candidate`
- 允许用途：线上展示、教练备课、产品验收
- 禁止用途：1,000 名学员正式开课、真实企业敏感数据、正式学习成绩

`package.json` 仍保留上游 `openmaic@0.3.0`；九轩阁产品版本由
`lib/jiuxuange/case-only/release.ts` 独立管理。

## 本版收口内容

1. `pnpm generate:jiuxuange-cases` 成为五案例统一可复跑生成入口。
2. 生成顺序固定为社区早餐连锁、便利蜂、生鲜零售、SHEIN、花西子。
3. 每个案例都包含 10 个场景和 5 道必需互动，完成当前案例后由服务端开放下一案例。
4. 便利蜂从无法重建的旧课堂 JSON 改为稳定语义 ID 的可复跑课堂定义。
5. 删除固定回收期、必然高估值等缺少完整证据的强断言，改为需由周转、损耗、单店现金和扩张结果验证的因果链。
6. 教练答案 V2 由最终课堂包自动提取，每道题的参考答案和解释与学员课堂同源。
7. 学员首次加载仍移除 `answer`、`hasAnswer`、`analysis` 和 `commentPrompt`，教练文档直链仍返回 `404`。

## 内容和正式使用边界

- 社区早餐连锁是明确的原创教学情境，不对应真实企业。
- 便利蜂、生鲜零售、SHEIN 和花西子均按课程历史材料口径讲授，不代表当前实时经营事实。
- 五个案例仍为 `pending_named_sme_review`；完整生成和技术通过不等于具名教研签署。
- 匿名预览身份不支持花名、企微和真实跨设备学员身份。
- 未执行 1,000 人容量、PITR、备份恢复和正式运维演练。
