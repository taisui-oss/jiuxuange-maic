# 九轩阁 MAIC 6.1.0-rc.1 发布验收记录

## 发布决策

- 产品版本: `6.1.0-rc.1`
- 名称: 九轩阁 MAIC 五案例闯关展示候选版
- 发布通道: `preview-candidate`
- 允许用途: 线上展示、教练和产品验收
- 禁止用途: 1,000 名学员正式开课、真实企业敏感数据、正式学习成绩

`package.json` 仍保留上游 `openmaic@0.3.0`。九轩阁产品版本由
`lib/jiuxuange/case-only/release.ts` 独立管理，避免伪装上游包版本。

## 本版内容

1. 五个完整商业模式案例，每个案例 10 个场景、5 道必需互动。
2. PostgreSQL 服务端权威进度、顺序解锁、幂等提交和乐观并发控制。
3. `content_version` 与 `progress_version`。
4. 学员版与教练答案分离，未解锁案例和关闭功能返回 `404/403`。
5. Netlify 管理数据库支持，由 Netlify 在发布前执行版本化原生 migration。
6. 匿名预览身份：每个浏览器生成一个 HttpOnly UUID，用于隔离展示进度。
7. 页面和只读 API 显示实际九轩阁版本号。
8. Case-only 构建使用独立轻量 SVG 场景渲染器；普通 OpenMAIC 构建仍保留原播放器、
   制作首页和 Provider 能力。

## 预览身份边界

- 同一浏览器刷新、关闭后重开、清除 `localStorage` 后，进度由服务端恢复。
- 不同浏览器默认是不同展示用户，进度不串号。
- 不支持跨设备恢复；待正式花名与企微登录把学员绑定到内部 `user_id` 后才能成立。
- 不采集姓名、手机号或企微标识，不得将它宣称为正式身份系统。

## 已知限制

- 五个案例仍为 `pending_named_sme_review`，技术完整不等于具名教研批准。
- 未接 OSS，课堂包仍在 Git 仓库。
- 未接花名、企微、正式权限和跨设备身份。
- 未执行 1,000 人峰值容量、备份恢复、PITR 和正式运维演练。
- Next.js 16 已提示 `middleware` 约定未来需迁移到 `proxy`，本版不影响运行。
- `--maxWorkers=4` 的全量 Vitest 中，两个既有课堂生成测试文件出现 3 项 5 秒超时或 Mock
  竞争；这 3 项单独复跑均通过。Case-only 数据库集成文件 4/4 单独通过。
- 本版不开发 OSS、Agent 讨论、项目卡和个人项目测评。
