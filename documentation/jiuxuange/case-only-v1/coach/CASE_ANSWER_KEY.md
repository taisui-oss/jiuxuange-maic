## 社区早餐连锁

- 来源：原创教学情境，不对应具体企业
- SHA-256：`not-applicable`
- 页码：不适用
- 证据边界：所有企业、门店、交易与经营数字均为教学设定。

### 六要素参考因果链

通勤者的速度与稳定需求 → 中央厨房与轻门店 → 预测和标准化 → 单店利润与现金 → 可复制价值。

### 原生互动：六要素因果关系

1. **该案例把工作日通勤者作为主要客户，最直接影响的是哪一项选择？**
   - 参考答案：A. 门店必须覆盖通勤高频路径并强调快速稳定交付
   - 解释：定位首先约束交付场景与价值主张，不会自动推出最大产能、全品类自制或单一收入方式。

2. **中央厨房与轻门店组合最需要哪一项能力来避免“缺货与报损同时发生”？**
   - 参考答案：B. 分门店、时段和天气的需求预测能力
   - 解释：中央预制依赖更准确的需求预测，否则集中生产会同时放大缺货和报损。

3. **为什么营业收入增长不能单独证明盈利模式成立？**
   - 参考答案：B. 门店扩张可能同步增加租金、人员、配送和损耗
   - 解释：盈利模式需要同时观察收入、成本和利益分配，扩张可能让成本快于收入增长。

4. **以下哪一项最能说明现金流结构，而不只是利润表现？**
   - 参考答案：A. 团餐收入可能月结，而房租、备货和设备投入先发生
   - 解释：现金流结构关注资金流入、流出和占用的时间差。

5. **以下哪条因果链最符合本案例的六要素逻辑？**
   - 参考答案：B. 通勤需求 → 轻门店与中央厨房 → 预测和标准化 → 单店现金成立 → 可复制价值
   - 解释：正确因果链必须从定位出发，经过业务系统和能力，再落到盈利、现金流与可复制价值。

## 便利蜂

- 来源：便利蜂商业模式.pdf
- SHA-256：`b5162cb5d933e7160d8910b4bce66f9d09de0be8f59c82e4b4f18161eee854e3`
- 页码：2-9
- 证据边界：按课程材料中的历史案例口径讲授，不代表企业当前实时经营状态。

### 六要素参考因果链

社区即时需求 → 中央大脑与门店执行 → 数据决策能力 → 周转与运营效率 → 可复制门店价值。

### 第一轮互动：定位与业务系统

1. **以下哪一项最能描述本课中便利蜂的定位？**
   - 参考答案：B. 以数据决策支持城市高频即时需求
   - 解释：课程案例把便利蜂放在城市高频即时需求中，数据决策用于支撑商品、库存和服务交付。

2. **“中央决策、门店执行”最直接改变了什么？**
   - 参考答案：B. 决策权、执行责任和反馈方式
   - 解释：数字化系统的业务意义在于重新分配决策、执行与反馈，而不是取消门店交付责任。

3. **判断这套业务系统是否成立，最应优先检查什么？**
   - 参考答案：B. 数据、决策、执行和反馈是否形成闭环
   - 解释：只有数据可用、决策可执行、现场结果可反馈，中央系统才能持续改进门店运营。

### 第二轮互动：能力、现金与价值

1. **便利蜂案例中最关键的能力组合是什么？**
   - 参考答案：B. 数据回流、决策模型与门店标准执行
   - 解释：案例的核心不是单一算法，而是数据、模型和现场执行形成的可反馈组合。

2. **哪条因果链最符合本案例的六要素逻辑？**
   - 参考答案：B. 高频需求 → 中央决策与门店执行 → 数据能力 → 经营与现金验证 → 可持续价值
   - 解释：正确链条从需求和定位出发，经过业务系统与能力，最终仍需由经营和现金结果验证企业价值。

## 生鲜零售

- 来源：生鲜零售行业商业模式对比.pdf
- SHA-256：`143d8f315ed246ca3224cc2b11f067476a519d3b12bbf3322d534298265a3a36`
- 页码：4-27，重点 7-10、17-24
- 证据边界：比较钱大妈、叮咚买菜与美团优选的课程历史样本，不外推为当前行业排名。

### 六要素参考因果链

客户场景 → 履约系统 → 专属能力 → 单位经济与现金 → 在特定条件下可复制的价值。

### 第一轮互动：定位与系统

1. **哪一种模式最符合“预售聚单、次日到团、社区自提”？**
   - 参考答案：C. 美团优选社区团购
   - 解释：课程材料中的美团优选采用预售聚单和团长自提，以计划性换取更低履约不确定性。

2. **哪一种模式最依赖较高客单价来摊薄骑手即时配送成本？**
   - 参考答案：A. 叮咚买菜前置仓到家
   - 解释：前置仓即时到家需要仓内拣货和骑手配送，客单价与订单密度直接影响履约成本占比。

3. **比较三种生鲜模式的业务系统时，最应优先核对哪组问题？**
   - 参考答案：B. 库存由谁持有、最后一公里由谁完成
   - 解释：库存与履约责任决定资产、损耗、服务和现金压力，是业务系统比较的关键。

### 第二轮互动：现金与价值

1. **相比前置仓即时到家，预售加社区自提最直接改变了什么？**
   - 参考答案：B. 降低需求不确定性和最后一公里即时配送压力
   - 解释：预售和自提可以降低部分需求与末端履约压力，但不会消除库存、仓配或盈利风险。

2. **哪条因果链最符合本案例的六要素逻辑？**
   - 参考答案：B. 客户场景 → 履约系统 → 专属能力 → 单位经济与现金 → 可复制价值
   - 解释：正确链条从客户场景出发，经过业务系统和能力，再落到单位经济、现金与可复制价值。

## SHEIN

- 来源：Shein的业务系统与关键资源能力.pdf
- SHA-256：`09512ebf61fdf910080f458404251b905ebdc4eeedcde643f3c8c22cc60dc05f`
- 页码：5-16，重点 5-11
- 证据边界：按课程材料中的历史案例机制讲授；不使用 OCR 不稳定的精确成本百分比。

### 六要素参考因果链

需求数据 → 小单测试 → 数字化追单与柔性供应 → 周转和复购 → 可复制现金价值。

### 第一轮互动：定位与系统

1. **课程材料中的小批量首单，首要目的是什么？**
   - 参考答案：B. 用较小库存测试真实需求并决定是否追单
   - 解释：小批量首单的核心是低成本验证需求，再依据真实反馈追加，而不是保证最低价格或转移全部风险。

2. **哪一项最能描述平台与供应商之间的系统关系？**
   - 参考答案：B. 数字化订单分配、流程协同与稳定结算共同支撑快反
   - 解释：快反需要数字化订单和流程协同，也需要结算与激励维持供应商长期合作。

3. **“多款、快上新、可负担价格”最直接要求什么业务系统？**
   - 参考答案：B. 小单测试、数据反馈和快速追单
   - 解释：多款与低价并存会放大库存风险，因此需要小单测试、反馈和追单来控制试错成本。

### 第二轮互动：现金与价值

1. **仅知道“首单批量小”，还不能证明现金流更好。最需要继续核对什么？**
   - 参考答案：B. 售罄、追单周期、退货、物流和供应商付款
   - 解释：小首单只覆盖初始试错，完整现金结构还取决于售罄、追单、退货、物流与付款周期。

2. **哪条因果链最符合本案例？**
   - 参考答案：B. 需求数据 → 小单测试 → 快速追单 → 周转和复购 → 可复制现金价值
   - 解释：案例的核心是用数据和小单快反提高学习与周转效率，最终仍需由复购和现金结果验证。

## 花西子

- 来源：花西子商业模式研究.pdf
- SHA-256：`e0135dcfaba0b33e2a0e55816ca59203dfca2383c996224131d17ba79e89a046`
- 页码：2-8
- 证据边界：按课程材料中的历史案例口径讲授；GMV、SKU 等数字不作为当前实时事实。

### 六要素参考因果链

东方彩妆定位 → 产品与内容一致 → 反馈迭代 → 复购与获客回收 → 可持续品牌价值。

### 第一轮互动：定位与系统

1. **什么最能证明“东方彩妆”已经进入经营定位，而不只是口号？**
   - 参考答案：B. 产品、包装、设计、内容和渠道表达保持一致
   - 解释：定位需要进入产品与交易系统，由多个触点共同兑现，而不是只在传播中出现。

2. **哪一项最符合花西子课程案例中的业务系统？**
   - 参考答案：B. 品牌组织代工、设计、内容平台和消费者反馈共同迭代
   - 解释：课程材料显示品牌通过外部生产和设计资源、内容平台与线上反馈形成协同系统。

3. **课程材料记录 SKU 较多且头部产品贡献集中，这更支持哪一判断？**
   - 参考答案：B. 企业通过测试迭代并把资源集中到有效产品
   - 解释：SKU 和头部集中更适合用来观察测试、筛选与资源集中，不能推出每个产品都成功或现金必然更好。

### 第二轮互动：现金与价值

1. **为什么不能从课程材料中的历史 GMV 直接判断自由现金流？**
   - 参考答案：B. 还缺库存、代工付款、平台结算、内容投入和退货证据
   - 解释：GMV 是交易规模，现金结果还取决于成本、付款与结算时点、库存和退货。

2. **哪条因果链最符合本案例？**
   - 参考答案：B. 定位一致 → 产品与内容协同 → 反馈迭代 → 复购与现金 → 品牌价值
   - 解释：长期价值需要定位通过系统和能力进入产品结果，并最终由复购和现金验证。
